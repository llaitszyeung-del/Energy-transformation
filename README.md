# 草原食物鏈能量探究

學生網址：https://llaitszyeung-del.github.io/Energy-transformation/

六個階段，追蹤草、斑馬和獅子之間的化學能轉移。

- 繁體中文及英語切換，保留學生進度及答案。
- 連續動畫，支援暫停、繼續、重播及跳過。
- 選擇答案後即時回饋；各關全部答對後自動顯示重點。
- 圓餅圖追蹤教學示例：100 → 80 → 60 → 55 → 15 → 8。
- 最後8單位代表獅子攝入量，不是新形成獅子組織的能量；數值並非固定比例。
- 沒有教師導覽或切換模式。進度只儲存在目前瀏覽器。

`index.html` 是完整單檔網頁，可用瀏覽器直接開啟，亦可在靜態主機發佈。無需安裝套件、登入或後端服務。

根目錄的 `app.js`、`layout.css`、`illustrations.js`、`i18n.js` 是與單檔網頁相同版本的程式和樣式；正式頁面已內嵌這些內容。
